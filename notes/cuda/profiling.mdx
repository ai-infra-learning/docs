---
title: "CUDA 性能分析"
description: "使用 Nsight Systems、Nsight Compute 与 Roofline 定位 GPU 性能瓶颈"
---

性能分析先确定时间花在哪里，再进入单个 Kernel 检查原因。端到端时间线和 Kernel 微架构指标属于两个不同层次，分别由 Nsight Systems 和 Nsight Compute 处理。

| 工具或方法 | 关注内容 |
|------------|----------|
| Nsight Systems | CPU/GPU 时间线、Kernel Launch、同步、内存拷贝和计算通信重叠 |
| Nsight Compute | 单个 Kernel 的指令、访存、Occupancy、Warp Stall 和硬件单元利用率 |
| Roofline | 根据 Arithmetic Intensity 与硬件上限判断 Kernel 更接近计算瓶颈还是带宽瓶颈 |

分析顺序通常从 Nsight Systems 的长时间空闲、同步和小 Kernel 问题开始，再对占用主要执行时间的 Kernel 使用 Nsight Compute。Roofline 用于建立瓶颈方向，具体优化仍需要结合访存事务、指令吞吐和 Warp Stall 指标。
